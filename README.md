## 🔧 Featured Projects

### [Crop Health Classifier](https://github.com/Khushdeep899/crop-health-classifier) · [Live Demo](https://leaffhealth.vercel.app/#demo)
Deep learning web app that identifies crop diseases from leaf images. PyTorch transfer learning (MobileNetV2) trained on 54,000+ images, 93%+ accuracy across 38 disease classes, served behind a FastAPI inference API.
**Stack:** PyTorch · FastAPI · React · Docker · AWS EC2 · GitHub Actions CI/CD

### [StencilFlow](https://github.com/Khushdeep899/StencilFlow)
Hybrid MPI + OpenMP 2D heat-equation solver in modern C++17. 1D domain decomposition, halo exchange via `MPI_Sendrecv`, double-buffered stencil updates, and byte-identical validation between serial and parallel runs. Hits ~1.35 billion cell-updates/sec on Apple Silicon, with strong and weak scaling plots in the README.
**Stack:** C++17 · MPI (OpenMPI) · OpenMP · CMake · GoogleTest · Docker · GitHub Actions

### [LogTriage++](https://github.com/Khushdeep899/LogTriagePP)
High-performance C++17 log-triage tool. Parses and normalizes log streams, clusters them by signature, and ranks recurring issues by severity and frequency. Parallel parsing via `std::thread`, JSON/text output, CI-friendly exit codes.
**Stack:** C++17 · std::thread · producer-consumer queue · CMake · GoogleTest
